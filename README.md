# BRAIN — 社区拥有的 AI

这是一个概念验证网站，展示 BRAIN 项目的愿景：一个由社区共同拥有和治理的 AI 生态。

## 本地预览

```bash
# 方式一：直接打开
open index.html

# 方式二：启动本地服务器
python3 -m http.server 8080
# 访问 http://localhost:8080
```

## 部署到 GitHub Pages

1. 在 GitHub 创建新仓库（公开或私有）
2. 推送代码：
   ```bash
   git add .
   git commit -m "Initial commit"
   git remote add origin <你的仓库地址>
   git push -u origin master
   ```
3. 仓库 Settings → Pages → 选择 master branch → 保存
4. 等待 1-2 分钟，你的网站就上线了
