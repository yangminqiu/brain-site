Section 03

🧠 Knowledge Base (RAG) — Community-Curated Intelligence

RAG stands for Retrieval-Augmented Generation. Instead of retraining the model, we build a community-curated database of knowledge that the AI references in real-time when answering questions.

How it works:

  • Community members submit knowledge — tutorials, articles, code snippets, Q&As, research notes
  • Each submission costs a small amount of $MINDAI (anti-spam mechanism)
  • Token holders vote on submissions. If quality content gets accepted, both the submitter and the voters earn $MINDAI rewards
  • Accepted content is vectorized and stored in a searchable index
  • When a user asks a question, the AI first retrieves the most relevant knowledge from this index, then generates an answer using both the retrieved context and its base model capabilities
  • Transparency: The AI cites its sources — every answer is traceable back to the community submission it drew from

Section 04

🔧 Fine-Tuning (LoRA) — Lightweight Adaptation

LoRA (Low-Rank Adaptation) is a fine-tuning technique that adapts large models using minimal compute. Instead of updating all 70B+ parameters, LoRA trains a small set of "adapter" weights that can be applied on top of the frozen base model.

Key benefits for MIND AI:

  • Runs on consumer hardware — a single RTX 5090 can complete a LoRA fine-tune in approximately 2 days
  • LoRA weights are small (megabytes, not gigabytes) — small enough to be stored on-chain or distributed via the community
  • No billion-dollar GPU cluster required — democratizing AI development
  • Periodic fine-tuning internalizes common community knowledge, making the AI faster and more accurate without RAG retrieval every time

As the knowledge base grows, we periodically fine-tune a LoRA adapter that captures the most frequently accessed community knowledge. This means common questions get answered instantly, while the RAG system handles specific, novel queries.
